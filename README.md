007-super-agent
全新超级 Agent 007：合并二号（判断/分诊）与三号（执行）全部能力的单体超级 Agent，采用 Go 单文件原生部署、无沙箱无限制直通执行，测试机为美国洛杉矶 VM124655。
核心特性
部署形态：Go 单静态二进制原生部署（super-agent）+ deps.sh 环境脚本 + systemd 守护。
权限策略：专用服务器无沙箱、无白名单/黑名单、无安全断路器，完整权限直通执行，仅保留 ledger.db 旁路无感记账。
分诊与索引：前置两级分诊 + L1/L2/L3 三级工具懒加载，适配 DeepSeek 前缀缓存与独立上下文监工（Advisor）。
测试环境：美国洛杉矶测试机 VM124655（4 vCPU / 4 GiB / 80 GiB）。
